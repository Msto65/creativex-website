CreativeX — موقع عربي متجاوب

الملفات:
- index.html: الموقع الكامل (HTML/CSS/JavaScript) دون مكتبات مدفوعة.

للمعاينة:
افتح index.html في متصفحك.

للنشر مجانًا:
1. أنشئ حسابًا في GitHub إن لم يكن لديك حساب.
2. أنشئ مستودعًا جديدًا باسم creativex-site.
3. ارفع index.html إلى المستودع.
4. افتح Settings > Pages.
5. اختر Deploy from a branch، ثم main و /(root)، واضغط Save.
6. انتظر ظهور رابط الموقع في صفحة Pages.

ملاحظة: نموذج التواصل لا يرسل الرسائل إلى بريد أو واتساب بعد؛ هو يجهز نص الرسالة فقط. أضف رقمك أو وسيلة تواصلك قبل نشر الموقع. الأمثلة في معرض الأعمال تجريبية.
